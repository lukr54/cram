# Third-party licence texts

Full licence text for the third-party crates statically linked into Cram's binaries, for the shipped
target `x86_64-pc-windows-gnu` with the release feature set `download,zstd-c,phash`. The graph is
resolved across the whole workspace, so it covers every artifact in the release zip, `cram.exe`,
`cram-extract.exe` and `cram_shell.dll`, not the CLI alone. Generated by `cargo about` from each
crate's own `LICENSE` file. This file is distributed alongside the executables; see
`THIRD-PARTY-NOTICES.md` for the hand-curated notices (UnRAR, the bundled C zstd library, etc.).
